# Buildlog

> An engineering log documenting my journey of learning, building, and improving AI/ML and GenAI systems.

This repository is a record of real work — not polished tutorials, not demos. Each project starts
from a genuine attempt to understand something deeply, goes through iteration and failure, and ends
with a working system and documented lessons. Projects build on each other; the understanding from
one feeds directly into the next.

## Philosophy

This is not a portfolio. It is an evolving engineering log where every project represents a real
problem I worked through — including the parts that didn't work. The goal is compounding depth:
each project inherits the lessons of the last and pushes further. Progress over polish.
